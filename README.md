# Criterion Check

A study tool for IB MYP students. Paste the task and your work, pick the criteria, and get the strict mark an examiner would give out of 8, with what held it back and one thing to fix.

## How it works

- Runs entirely in your browser. There is no server.
- You paste your own API key for Claude (Anthropic), ChatGPT (OpenAI) or Gemini (Google). The page sends your work straight to the provider you choose, and grading is billed to your own account.
- Keys are not stored unless you tick "Remember this key on this device". A content security policy limits the page to talking to those three providers and the libraries it loads.
- Work can be pasted text, PDF, Word, text files, screenshots, or saved web pages (.mhtml, .html).

Unofficial and not affiliated with the IB. Marks are an estimate, not an official grade.
